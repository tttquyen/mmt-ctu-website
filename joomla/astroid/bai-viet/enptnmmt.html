Head of laboratory: Assoc. Prof. Dr. Do Thanh Nghi

Development orientation

The laboratory focuses on three main areas: computer networks, high-performance computing and data science.

The College of ICT has invested seriously in both facilities and research staff. In return, the laboratory has contributed numerous ISI-ranked international publications, projects and scholarships, and in particular has improved teaching so that it keeps pace with new research directions and technologies.

Cloud computing infrastructure

The laboratory has successfully deployed the private cloud of the College of ICT (cloud.cit.ctu.edu.vn/horizon), bringing considerable benefits to the teaching activities of the College and of Can Tho University.

Cloud computing is a comprehensive information technology solution that uses computing technologies and servers developed over the Internet. It creates a virtual working environment that helps organisations provide resources flexibly while significantly reducing investment, maintenance and energy costs.

Requesting virtual machines on CitCloud

CitCloud runs on six high-end servers operated by the Faculty and provides Ubuntu Server virtual machines for lab work, research and specialised projects. Windows machines are issued only when the user supplies the software licence. Requests are served in this order: teaching support (e.g. servers for web or network programming labs), research, College projects, then technology-transfer projects.

  1. RequestFill in the form: name, e-mail, unit, purpose, period of use, configuration (CPU, RAM, disk) and number of machines.
  2. ReviewThe laboratory assistant checks system capacity.
  3. ApprovalThe head of laboratory or the Faculty leadership confirms the request.
  4. ProvisioningThe user receives an IP address and an account and connects via SSH (Linux) or PuTTY (Windows); allocations are published.
  • Use the machine only for the stated purpose; change the password on receipt and take responsibility for security and licences.
  • CitCloud provides computing for the registered period only, not long-term storage.
  • Exposing services to the Internet requires permission from the College leadership.
